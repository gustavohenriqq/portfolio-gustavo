Trabalho na **AMBEV S.A** na interface entre dados e a operação financeira/logística, onde construí do zero uma solução de BI em produção: modelo semântico em **Power BI** com mais de 30 medidas DAX, atualizado automaticamente via SharePoint, com indicadores como IOH, Orçamento Base Zero, inventário SOX e devoluções para a liderança, eliminando um report antes 100% manual.

Na **engenharia de dados**, finalizei o pipeline da **Copa do Mundo 2026**: 6 fontes públicas, modelagem dimensional com **dbt** (staging → marts com testes), PostgreSQL na nuvem e um dashboard de 11 páginas no Looker Studio, online 24/7. No **desenvolvimento**, construo aplicações full stack com foco em back-end, APIs REST e sistemas orientados a negócio. E uso **IA generativa** (Claude com MCP, Gemini) na rotina para automatizar análises.
